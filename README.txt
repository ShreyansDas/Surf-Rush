SURF RUSH - Endless Wave Rider

Files (keep them together in one folder):
  index.html    - open this to play
  style.css     - menus, HUD and screens
  game.js       - the game
  three.min.js  - 3D engine (three.js r128), included so the game works offline

How to play:
  Double-click index.html to open it in Chrome, Edge, Firefox or Safari.
  To play on a phone, upload all four files to the same folder on a web host
  (for example Neocities, GitHub Pages or Netlify) and open the page's address.

Controls:
  Phone     - swipe left/right to move, up to jump, down to duck
  Mouse     - move the cursor to steer, left-click to jump, right-click to duck
              (turn off "Cursor steering" in Settings to drag-swipe instead)
  Keyboard  - arrow keys or WASD, Space to jump, Esc or P to pause

Progress is saved in the browser on the device you play on.
Fonts load from Google Fonts when online; offline the game uses system fonts.
